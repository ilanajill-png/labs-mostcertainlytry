# Las Jaras Being Research Notes Protocol

Created: 2026-06-11

Purpose: give every Las Jaras household being a clear habit for researching purchases, articles, tools, products, references, and inspiration connected to the things it manages.

## Core Rule

Each being should notice new items, articles, tools, products, references, and ideas inside its jurisdiction. When something is interesting, it should make a short note with why it matters, what decision it may affect, and whether it belongs in a private research file, a visual board, a public story, or a shopping review.

## Where Notes Should Live

Primary home: Las Jaras private research notes.

- Use markdown/Labs working files for actual decisions, source links, prices, notes, warnings, and next actions.
- Use daily notes for quick observations and recurring watch items.
- Use public Labs pages only after private details are removed.

Pinterest:

- Best for visual research: rooms, gardens, materials, lighting mood, guest-room styling, xeriscape references, table settings, bath rituals, textiles, exterior details, and product lookalikes.
- Treat Pinterest as a mood board, not the source of truth.
- Every pin-worthy idea should still have a private note if it affects a purchase or design decision.

## Daily Pinterest Link Feed

Assignment: Sundries feeds Mira Queue, the Social Media Manager, a daily Pinterest link packet.

Purpose: keep useful household objects, storage ideas, supply systems, product references, labels, organizers, cart-adjacent finds, and practical how-to visuals flowing into visual memory without turning every find into a purchase or public post.

Sundries' daily packet should include:

- 3-7 links, unless there are no useful finds that day.
- A one-line reason each link matters.
- Category: storage / pantry / cleaning / laundry / bathroom / guest supplies / kitchen tool / garden supply / product lookalike / other.
- Pinterest pin type: image / video / recipe rich pin / article rich pin / product rich pin / product pin / not Pinterest-suitable.
- Relevance: useful now / watch later / compare before buying / visual reference only.
- Purchase status: no purchase / maybe / needs Penny Cobalt review / needs Ilana review.
- Privacy status: private only / Pinterest candidate / Labs reference candidate.

Mira Queue reviews the packet and sorts each link:

- Private note: useful, but not visual or public-safe.
- Pinterest board candidate: visual, household-relevant, safe to save as inspiration, and matched to the correct pin type.
- Labs reference candidate: useful for a future public-safe project page or build note.
- Reject: too generic, too salesy, irrelevant, or not aligned with Las Jaras.

Pinterest pin-type guide:

- Image pin: one strong still image, such as an organizer, room detail, label system, supply setup, tool, before/after, or product lookalike.
- Video pin: motion or multi-step visual reference, such as a folding method, cleaning demo, drawer reset, decanting flow, or room setup.
- Recipe rich pin: recipe source that can carry title, servings, cook time, ratings, diet preference, and ingredients from the source site.
- Article rich pin: article or blog source where description, author, headline, or title matters.
- Product rich pin / product pin: purchasable item with price, availability, product details, or retailer destination. Route purchase-relevant items to Penny Cobalt before Ilana review.
- Not Pinterest-suitable: private, nonvisual, sensitive, account-gated, low-quality, duplicated, or mainly operational.

Mira does not pin, post, publish, affiliate-link, or create public content without Ilana's approval. The daily handoff creates a queue for review, not an action that leaves the house.

Instagram:

- Best for public-facing storytelling after an idea becomes clear: before/after moments, build notes, house lore, short rituals, product trials, and Las Jaras atmosphere.
- Do not use Instagram as the working research archive.
- Social Media Manager drafts; Ilana approves before posting.

Recommended structure:

1. Private note first.
2. Pinterest if visual.
3. Labs if useful to the project story.
4. Instagram only when it is public-safe, beautiful, and intentional.

## Guardrails

- No spending, checkout, account creation, affiliate application, or public post without Ilana's approval.
- Do not store passwords, private account details, or sensitive personal information in public notes.
- If a source is only inspiration, label it as inspiration.
- If a source affects safety, installation, electrical work, health, or privacy, route it to Officer Ember or Soma before acting.
